📻 Política de Privacidad

Última actualización:

Bienvenido a Konata Station Radio App (la "Aplicación"). Esta Política explica cómo recopilamos, usamos y protegemos tu información al utilizar nuestra radio online y el sistema de peticiones por Discord.

✅ Resumen rápido: Recopilamos datos de ubicación (aproximada), sistema operativo y user agent con fines estadísticos. Si usas el sistema de peticiones mediante Discord, almacenamos tu correo y usuario de Discord según las políticas de la plataforma.

1. Información que recopilamos

📍 Datos de conexión y uso (fines estadísticos)

Cuando te conectas a nuestro servidor para escuchar la radio, nuestro backend recibe automáticamente:

  • Ubicación geográfica aproximada (basada en IP) → para gestión de audiencia y análisis estadístico por región.
  • User Agent → información del navegador o dispositivo.
  • Sistema operativo y versión (ej. Android 14, iOS 17, Windows 11).

Estos datos son anonimizados o agregados. No permiten identificar personalmente a los oyentes, solo nos ayudan a mejorar la calidad del streaming y entender mejor a nuestra comunidad.

🎤 Datos de Discord (sistema de peticiones)

Nuestra aplicación incluye un sistema para enviar peticiones de canciones usando Discord. Al utilizarlo:

  • La app se conecta a Discord mediante su API oficial para desarrolladores.
  • Guardamos en nuestro backend tu correo electrónico y nombre de usuario de Discord, únicamente cuando realizas una petición.
  • El tratamiento sigue las Políticas de Desarrollo de Discord y sus términos de privacidad.

Para más información sobre cómo gestiona Discord tus datos, visita: Política de Privacidad de Discord.

2. Finalidad del tratamiento

DatoFinalidad
Ubicación (aproximada)Estadísticas de audiencia, análisis geográfico agregado.
User Agent + SO versiónMétricas técnicas, compatibilidad y mejoras de rendimiento.
Email + usuario DiscordIdentificar al solicitante, gestionar peticiones y evitar abusos.

3. Base legal (RGPD / Ley 25.326 Argentina)

  • Interés legítimo: tratamiento de ubicación, sistema operativo y user agent para análisis estadístico y mejora del servicio.
  • Consentimiento del usuario: al usar el sistema de peticiones por Discord, aceptas el almacenamiento de tu correo y usuario de Discord según esta política.

4. Compartición de datos

No vendemos ni compartimos tus datos con terceros para marketing. Solo se comparten en estos casos:

  • Proveedores de infraestructura: servidores, bases de datos (siempre con acuerdos de confidencialidad).
  • Discord Inc.: durante la autenticación y uso del sistema de peticiones, bajo sus términos de desarrollador.
  • Obligación legal: requerimiento judicial o administrativo.

5. Seguridad y retención de datos

  • Los datos estadísticos (ubicación, SO, user agent) se conservan de forma agregada o se eliminan después de 12 meses.
  • Los datos de Discord se guardan mientras tu cuenta esté vinculada a nuestro sistema de peticiones.
  • Aplicamos medidas de seguridad estándar (cifrado en tránsito, accesos restringidos).

6. Tus derechos

Tienes derecho a acceder, rectificar, suprimir, tus datos personales. No obstante debido al proceso de ofuscación de los datos, no podemos garantizar que podamos realizar dicha opción.

7. Discord y políticas del desarrollador

El sistema de peticiones se acoge a los Términos de Desarrollo de Discord. No almacenamos más datos de los necesarios para la funcionalidad de peticiones y respetamos las condiciones de la API de Discord.

8. Cambios a esta política

Cualquier modificación importante será notificada a través de la aplicación o nuestro sitio web. Te recomendamos revisar esta página periódicamente.
